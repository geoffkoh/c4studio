# Tabler Icons, bundled (PP-239)

[Tabler Icons](https://tabler.io/icons) by Paweł Kuna, MIT licensed: see
`LICENSE`, which is Tabler's own and travels with every icon the Studio
copies into a workspace (`icons/tabler/LICENSE`).

`icons.json` is the outline style of the npm package `@tabler/icons`,
version, tarball and checksum at its top, as `[category, tags, shapes]`
per icon. The `brand-*` icons are left out: they are other companies'
logos, and brand logos come only from the curated Simple Icons subset.

Regenerate it with `scripts/vendor_tabler.py`; never edit it by hand.
